# 电影级代码视频导演法则 (Director Grammar)

> 吸收自 `lemo-opuscar` 导演体系（`DIRECTOR.md` & `TECHNIQUE.md`）。
> **你不是在做 Tech Demo，你是在当导演。** 一支代码视频的成败按此顺序评判：**声音 (Sound) → 节奏 (Rhythm) → 镜头 (Camera) → 导演调度 (Directing)**。好看的静态单帧只是起点。

---

## 1. 先立标尺 (Find a Benchmark First)

动笔写分镜前，先针对当前文章主题与所选风格挑 1–2 个标杆作品（如 Apple/Linear 发布片、RSA 白板动画、Müller-Brockmann 瑞士网格海报、Vox 视觉调查）：
- **要学什么**：构图比例、叙事呼吸感、运镜语法（Camera Grammar）、色彩克制逻辑。
- **绝不照抄什么**：具体的设计元素、文案句式、Logo 或固定模板套路。

---

## 2. 故事弧线与「媒介原生大招」(One Native Move)

- **一个主角、一个目标、一次转折**：把文章的核心技术概念当成主角（从“痛点困境” → “认知转折” → “重构后的新秩序”）。
- **前 3 秒直接抓人**：严禁在片头做漫长无意义的 Logo 动画才进正题。
- **首尾呼应 (Bookend)**：结尾必须回扣开场的痛点，或者在最后一镜拉远展示全局（The Whole-Wall Reveal）。
- **至少一个「媒介原生大招 (Native Move)」**：
  在全片认知高潮处，必须设计一个**只有代码动画能做出来的视觉大招**：
  - *白板手绘风 (`whiteboard`)*：橡皮擦沿着原路径倒擦，象征“时间倒流 / 架构回滚”，留下 7% 的旧课残影（Ghost marks）；
  - *暗色科技发布风 (`dark-keynote`)*：原本杂乱无章生成的几十个微服务/Agent 窗口，在一个节拍内瞬间磁吸对齐成干净的网格（The Snap Grid）；
  - *瑞士网格风 (`swiss-motion`)*：一把锐利的裁纸刀线（Knife Cut）划过冗余模块，模块向中线坍缩消失，周围元素按距离依次重排（Re-flow）；
  - *工程简报墙 (`briefing-board`)*：全片每个镜头都是巨型白板墙的局部特写，直到最后一幕长拉远（Long pull-back），才第一次露出整面完整的架构全景图。

---

## 3. 相机语法：2D 画面也有真实的摄影机 (Camera Grammar)

拒绝死板固定机位“PPT 翻页”。构建统一的 `world → screen` 坐标变换，全片至少组合使用 **4 种不同语义的运镜**：

| 运镜动作 (Camera Move) | 视觉语义 (What it expresses) | 适用文章段落 |
| :--- | :--- | :--- |
| **跟线运镜 (Ride the line)** | 一个概念推导出下一个概念 | 调用链路、数据流转、因果推导 |
| **极近特写定格 (Locked ECU)** | 聚焦单一关键细节或一行核心代码 | 致命 Bug 定位、核心参数、关键判断 |
| **对数空间连续拉远 (Log Pull-back)** | 从单点膨胀为系统全局，展现规模失控 | 智能体蔓延、依赖爆炸、并发扩张 |
| **一拍急拉/急推 (Whip Pan / Pull)** | 强烈的转折（“但是……”）或因果同框 | 架构重构前后对比、真相揭晓 |
| **阶梯式构图 (Staircase Framing)** | 每个新方案都把上一个方案的结果留在画框边缘 | 多方案横评、性能指标对比、三步演进 |
| **全墙终极揭示 (Whole-Wall Reveal)** | 把整篇文章浓缩为一张可截图保存的完整架构海报 | 视频尾声总结 |

---

## 4. 节奏与阅读时间硬公式 (Pace for the Viewer)

节奏必须有快慢交替、有加速、有一次明显的“深呼吸（长停顿）”。匀速播放的视频等于失败。

- **画面文字停留硬公式 (`readcheck`)**：
  任何画面文字在入场动画彻底完成后，保持静止可读的时长必须满足：
  $$\text{停留秒数} \ge \frac{\text{中文字符数}}{4.5} + \frac{\text{英文字符数}}{15} + 1.5\text{ s}$$
- **字幕停留底线**：
  每条字幕至少停留 `1.8s`，且不短于 `语音朗读时长 + 0.6s`。
- **宁少勿快**：
  想做快节奏时，靠**减少同屏字数**来提速，绝不允许在观众还没读完字之前就切走画面。

## 5. 声音占影片的一半 (Sound is Half the Film)

- **可见动作皆有声 (Procedural Foley)**：
  利用内置的 `template/scripts/sfx.py` 为关键帧动作挂载物理音效：
  - 卡片落位/磁吸：`click()` / `clack()`
  - 镜头急推/横扫：`whoosh()`
  - 警示章盖下/重音落点：`thump()`
  - 核心收益/绿勾亮起：`ding()` / `pop()`
- **至少两处「真正的留白 (Silence)」**：
  在核心反直觉结论抛出前，让背景音与音效瞬间归零（停顿 0.5–1s），留白后的第一个声音将成为全片最抓耳的重音。
- **声音先行转场 (J-cut / L-cut)**：
  至少两处转场让下一幕的标志性音效提前 0.2–0.4 秒进入（J-cut），带动画面切换。
- **响度标准化**：
  人声先做动态压缩，压低背景乐（Ducking 8–10 dB），最终通过 `ffmpeg loudnorm` 统一母带响度至 **-14 LUFS**。
